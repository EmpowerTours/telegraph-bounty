Run a hunt yourself

Offline needs no keys. Live mode uses your own testnet wallet and your own Claude login, about $0.15 of test USDC per 5-target hunt.

git clone https://github.com/EmpowerTours/telegraph-bounty
cd telegraph-bounty && git submodule update --init && npm install
npm run demo:hunt
TELEGRAPH_MODE=live npm run demo:hunt
